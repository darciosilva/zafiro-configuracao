## 🚀 Começando do zero?

1. **Primeiro:** configure o modelo de LLM (módulo 01) — é a base de tudo.
2. **Depois:** otimize tokens (módulo 02) — economize créditos desde o início.
3. **Em seguida:** configure memória (módulo 03) — o agente passa a lembrar de você.
4. **Avance:** SSH, APIs, system prompt, skills e configuração geral.
5. **Por fim:** contribua com a comunidade (módulo 09).
