## Como enviar alterações

1. Faça um fork do repositório.
2. Crie um branch para sua modificação (`git checkout -b melhoria-doc`).
3. Adicione ou ajuste o conteúdo em Markdown.
4. Abra um Pull Request descrevendo as mudanças.

---

## Regras de envio

- Mantenha o texto direto e sem explicações desnecessárias.
- Não inclua senhas, tokens ou dados pessoais nos exemplos.
- Verifique se os caminhos e comandos funcionam na versão atual do Zafiro.
