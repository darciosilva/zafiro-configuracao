# Modelo LLM

Como configurar os modelos de linguagem no Zafiro.

---

## Provedores

| Provedor | Modelos | URL |
|----------|---------|-----|
| OpenAI | gpt-4o, gpt-4o-mini | platform.openai.com |
| Anthropic | claude-sonnet-4, claude-haiku | console.anthropic.com |
| Google | gemini-2.0-flash | aistudio.google.com |
| OpenRouter | Vários provedores | openrouter.ai |

---

## Configuração

1. Abra **Configurações → LLM**.
2. Escolha o provedor.
3. Cole a API key.
4. Altere a **Base URL** se necessário.
5. Salve.

---

## Parâmetros

- **Temperature:** `0.7`
- **Max tokens:** `4096`
- **Top-P:** `0.9`
