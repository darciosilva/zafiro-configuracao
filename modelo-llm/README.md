# 🤖 Modelo LLM

Como configurar os provedores de linguagem.

---

## 🔑 Provedores

| Provedor | Modelos | URL |
|----------|---------|-----|
| OpenAI | gpt-4o, gpt-4o-mini | platform.openai.com |
| Anthropic | claude-sonnet-4, claude-haiku | console.anthropic.com |
| Google | gemini-2.0-flash | aistudio.google.com |
| OpenRouter | Vários provedores | openrouter.ai |

---

## ⚙️ Configuração

1. Acesse **Configurações → LLM**.
2. Selecione o provedor e insira a API key.
3. Altere a **Base URL** (se aplicável).
4. Salve.

---

## 🎛️ Parâmetros

- **Temperature:** `0.7`
- **Max tokens:** `4096`
- **Top-P:** `0.9`
