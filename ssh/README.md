# 🔐 Integração SSH

Como conectar a servidores remotos e ao Termux.

---

## ⚙️ Configuração

1. Acesse **Configurações → SSH**.
2. Insira IP/hostname, porta e usuário.
3. Configure a autenticação por **Chave Privada** (recomendado) ou **Senha**.

---

## 💻 Comando

```
ssh@meu-servidor ls -la
```
