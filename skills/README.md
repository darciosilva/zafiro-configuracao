# Configuração de Skills

Como instalar e utilizar habilidades (skills) no Zafiro.

---

## O que é uma Skill

É uma pasta contendo um arquivo `SKILL.md` que fornece contexto, fluxos e regras para o agente executar tarefas específicas.

---

## Local de instalação

`/data/data/com.niki914.zafiro/files/skills/`

---

## Como instalar

### Via GitHub
Solicite ao agente:
```
Instale a skill do repositório https://github.com/usuario/repo
```

### Instalação manual
Copie a pasta da skill diretamente para o diretório de skills do aplicativo. As alterações entram em vigor no turno seguinte.
