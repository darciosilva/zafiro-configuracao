## 📝 Como contribuir

### 1. Reportar problemas (Issues)

- Acesse: https://github.com/darciosilva/zafiro-configuracao/issues
- Clique em **"New issue"**
- Descreva:
  - O que esperava
  - O que aconteceu
  - Passos para reproduzir
  - Versão do Zafiro e Android

### 2. Sugerir melhorias

- Abra uma issue com a tag `sugestão`
- Descreva o módulo ou seção que quer melhorar
- Se possível, inclua um exemplo

### 3. Enviar código/conteúdo (Pull Request)

1. Faça um **fork** do repositório
2. Crie um branch: `git checkout -b minha-melhoria`
3. Edite ou adicione arquivos
4. Commit: `git commit -m "Adiciona guia de X"`
5. Push: `git push origin minha-melhoria`
6. Abra um **Pull Request** no repositório original

### 4. Revisar conteúdo existente

- Verifique se as instruções ainda funcionam na versão atual do Zafiro
- Corrija links quebrados
- Atualize screenshots ou exemplos desatualizados

---

## 📐 Padrões de contribuição

- **Idioma:** Português (Brasil)
- **Formato:** Markdown
- **Estrutura:** siga o padrão dos módulos existentes (título, objetivo, passos, dicas, link para próximo)
- **Sem dados sensíveis:** nunca inclua tokens, senhas ou chaves reais
- **Teste antes:** verifique que os passos funcionam antes de submeter
